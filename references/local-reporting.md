## 本机适用范围与周会记录

- 这份本地 Skill 用于当前 GPT/Codex 账号在本机 macOS 用户 `yeahmobi` 的 Codex 环境中工作。权威同步来源是 `https://github.com/t9vrk7rzrt-wqc/my-ai-skill`；本机 `~/.codex/skills/personal-ai-work/` 是实际加载副本。
- 本机 `~/.codex` 配置本身不能可靠识别或区分不同 GPT 登录账号。若其他账号共用同一 macOS 用户和 `~/.codex`，不要声称已实现账号级自动隔离；需要彻底隔离时，应使用独立的 `CODEX_HOME`、配置环境或 macOS 用户。
- 生成周会、工作总结、近期经验回顾或工作量统计时，只使用能证明发生在这台电脑上的记录：`hostId: local` 的 Codex 任务、本机工作目录及文件、本机输出物、本机 Git 提交与修改记录，以及用户明确指定的本机证据。
- 不把普通 ChatGPT 云端会话、手机、其他电脑、远程主机或无法证明来自本机的记录纳入周会与工作总结。即使使用同一 GPT 账号，也按设备来源排除；来源不明时先询问用户。
- 周会记录从北京时间 `2026-09-21 00:00` 起建立本机基线。用户说“从上周开始往后”时，从该日期开始检索；以后按用户指定的统计周期或周会时间向后延续，不回填该日期之前的活动。
- 历史聊天可以作为查找本机文件和任务的线索，但只有本机路径、`hostId: local`、本机 Git 或其他本机证据能确认时才计入；不能仅凭聊天标题或云端摘要判断设备来源。
