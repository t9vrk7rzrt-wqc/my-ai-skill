# 视觉任务补充规范

仅在对应任务中读取；通用沟通、修改边界和验收规则见上级 `SKILL.md`。

## Figma 任务

- 排版准确与清晰度同等重要；不能为了高清破坏构图、位置、比例、裁切、字体、图标、圆角或层级。
- 精修任务以用户当前确认或手动调整后的版本为视觉母版。
- Figma 写入或需要程序化结构检查的任务默认同时使用 `personal-ai-work` 与 `figma-use`：先按本 Skill 明确修改边界和验收标准，再按 `figma-use` 检查、修改和验证。除非用户明确免除，完成前必须以实际画板截图复核，不能只凭图层数据或节点数值判断。
- 涉及结构化 JSON 导入、可编辑图层、本地插件、AppleScript（苹果脚本）菜单自动化、inspect（结构检查）、preview（预览核验）、像素扫描或空白边带裁剪时，必须先阅读 [Figma 桌面自动化工作流](figma-desktop-automation.md)。
- 普通 Figma 修改仍遵循本文件的修改边界与自查规则，不重复建立另一套通用规则。

## 品牌网站与视觉素材

- 用户近期主要处理德国市场的太阳能、阳台光伏和家庭能源网站，包括 Branding、About Us、Installation Guide、商品集合、ROI Calculator、认证奖项等页面。先理解页面目的、目标人群、产品形态和德国本地语境，再决定图片、图标与英文文案方向。
- 竞品网站只用于判断行业常见场景、构图和信息层级，不复用其图片、品牌元素、具体版式或可识别创意；产出应保持原创并符合用户自己的品牌气质。
- 商业 Hero 图和品牌图片优先真实可信：人物年龄、住宅环境、阳台结构、光伏板安装方式、光线和产品比例要合理，避免过度精致、塑料皮肤、异常肢体、伪文字和明显 AI 痕迹。
- 已确认整体构图后，后续问题优先做局部修复；例如手部、边缘或单个物体有问题时，只编辑必要区域并贴回原图，不重新生成太阳、天空、人物、产品、色温和其他已确认部分。
- 验收图片时同时检查原始分辨率、页面实际裁切比例和放大细节。人物手部、面部、产品结构、栏杆交叉、阴影衔接与文字留白属于重点检查项。
- 输出用于网页首屏时，要让品牌、真实产品或真实使用场景成为首屏明确视觉信号，并为标题、按钮和响应式裁切保留可用空间。

## 图标与 SVG

- 页面图标先保证语义直观，再统一风格。用户提供多个候选时，结合实际显示尺寸选择辨识度更高、细节更少、轮廓更清楚的一版，并说明判断依据。
- PNG 或风格不一致的 SVG 可以在保留语义的前提下重绘为可编辑 SVG；默认统一线宽、圆角端点、转角、颜色、细节密度、视觉占比和光学居中。
- 小尺寸图标必须按最终尺寸检查，尤其是 24×24 或 32×32。不能只看放大图；同时避免线条粘连、细节糊成块、越界、裁切和不同图标视觉重量失衡。
- 替换 Figma 图标时保留原容器、坐标、尺寸和周围布局，未指定的图标保持不变。完成后检查节点边界与实际画板截图，并为复用保存本次真正使用的 SVG 文件。
- 交付 SVG 前运行可用的语法校验；同时保留整组效果图和必要的局部放大图，让用户能快速确认整体一致性与单个图标细节。
