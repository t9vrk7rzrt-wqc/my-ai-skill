# 图标任务入口与交付边界

图标候选、语义选择、SVG精修、替换、实际尺寸验收和打包统一由 `figma-icon-replacement-qa` 维护。进入图标任务时读取当前安装的同名Skill；本仓库源文件是 [图标专项规范](../../figma-icon-replacement-qa/SKILL.md)。安装单个技能后，兄弟技能可能不在同一路径，应按技能名称发现，缺失时明确说明。

本文件仅保留Figma交付中的特殊衔接：

- 手机端适配时缩放完整图标容器，或明确只调整内部符号；不能漏掉圆底，不能把内部小符号放大成邻居的整容器尺寸。
- 图标的导出Frame只包含所需符号和底板，不混入卡片文案。媒体与文字分层仍按frontend-handoff.md处理。
- 页面布局适配不等于授权重画图标。当前图标已确认时沿用原资产；需要替换则进入图标专项流程。
