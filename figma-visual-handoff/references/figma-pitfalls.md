# 实际工作中的问题与修正

这些是遇到过的失败和处理依据。按触发条件使用，不把一次环境限制写成所有机器永久不可用。

## 输出、页面和重试

| 问题现象 | 处理 |
| --- | --- |
| 一次返回多页深层树，约 70KB，超过工具 48000-byte 限制 | 按模块查询，限定层级、文本样本和字段；不继续重复整树读取。 |
| 读取到另一页，或旧 ID 找不到 | 每次调用重新定位页面，`await figma.setCurrentPageAsync(page)`；跨页分开调用，不把同步赋值当可用路线。旧 ID 按语义重新解析。 |
| 写入中途失败，重跑产生重复稿 | 读取工具 `safeToRetryWithoutCanvasRead`。明确可安全重试时改错后重试；否则先检查实际画布，只清理本次创建且已识别的残留。不能推测所有失败都会回滚。 |
| 日志打印了结果但工具没有返回 | 使用结构化 `return`，返回全部创建/修改/删除的节点 ID；不依靠 `console.log`，不调用未支持的通知方法。 |

## 自动布局和尺寸

- `resize()` 可能重置尺寸策略。先设合理尺寸，再设置 HUG/FILL 等策略；FILL 需要已经处于允许的父自动布局中，不能在任意孤立节点上使用。
- 横向行的主轴通常固定宽度，交叉轴随内容高度增长；纵向列表通常固定宽度、随内容增长。曾经给横向 FAQ/联系行保留默认 100px 交叉轴高度，导致无意义大空白；应按行的真实内容恢复高度自适应。
- 图片克隆继承 FILL 后，加入较窄父容器会先改变宽度。此时再按源节点宽度计算缩放，会发生二次缩小并出现白边。先固定克隆的尺寸策略，再放进容器并计算实际尺寸；单一图片矩形可按目标比例直接设尺寸。嵌套蒙版须检查内外层边界。
- 绝对背景在被标为绝对定位前，可能短暂参与布局，抬高父容器。先完成绝对定位，布局稳定后再按父容器实际高度设置背景；检查背景没有延伸到下一模块。
- 不同边框粗细的 `strokeWeight` 可能是 `figma.mixed`，不能当数字赋值。先判断数值类型，必要时逐边复制；保留 FAQ 的上下分隔线，不顺手加四边框。
- 访问类型专属属性前判断节点类型/能力；不要对所有节点读取 `characters`、`children`、`layoutMode` 或组件属性。

## 字体与图标

- 按当前文字的实际字体及样式加载，再改文字或重组包含文字的节点。查询可用字体确认真实样式拼写，不猜 `SemiBold` / `Semi Bold`。
- Arial 在这次 Figma 工具中加载失败，并曾导致 PDF 标记的父节点重组失败。这是环境事实，不是所有文件都应全局替换字体的理由。优先保持可用原字体；某个小标记确需重建时，只对该新标记使用本网站已有可用字体并核对画面；正文/品牌字体缺失且不能保真时说明限制，不静默替换全页。
- 图标不能用“第一个 INSTANCE”代表完整图标。实例可能只是圆底里的内部符号；应明确读到背景容器与内部符号层级，再按一致比例处理。
- 检查文本绑定变量、字距和大小写；设置字号成功不意味着文字一定能放下。一次 Download Manual 在 111px 文本宽度中断为两行，调整文字可用宽度后才恢复单行。

## 截图与资源验证

- 长截图缩成 2048px 预览时可能掩盖按钮换行或小图标差异。使用同一张高分辨率截图的准确局部，或只对发现问题的位置补拍截图；不要把缩略图当实际尺寸验收。
- 临时图片 URL 要及时获取。下载后检查真实格式、尺寸和内容；文件存在不是已验收。
- 系统 Python 这次缺少 Pillow。改用已验证可用的图片运行时或系统工具；不要反复跑同一缺失依赖。`sips` 裁切的偏移含义须在副本上验证，本次曾未得到预期顶部区域，不能把错误裁片当顶部已检查。
- 同一张原图应能通过节点来源或 `imageHash` 对应；不把视觉相似的生成图宣称为原图。
- 已生成 Installation Guide 移动稿并做截图检查，不代表后来新增的媒体/文字分层交付要求已自动满足。旧稿必须重新做交付结构审核，不能追认“全部可交付前端”。

## Skill 和 GitHub 同步

- 按名称、描述和实际用途盘点本机与远端 Skill。新建整合型 Figma 交付 Skill 时，保留个人偏好 Skill 和已有专门图标 Skill，不为避免重名而伪装功能重复的多个版本。
- 校验当前 GitHub 身份、目标仓库和写权限。本次 GitHub 插件连接的账号与原仓库账号不一致且无写权限；本机 CLI 在获准联网核验后可确认原账号。不能用错误账号上传、擅自另建仓库或退出其他浏览器账号。
- 网络受限时的一次登录状态失败不应直接定论为令牌失效；按环境审批规则核验，仍无权限时保留已验证的本地成品，明确上传未完成。
- 只新增本 Skill 对应目录，保留远端其他文件，检查提交范围和同步后的实际文件。不要强制覆盖远端分支，也不要把本机密钥、客户源图或日志一并推送。
