# 任务卡、提示词与交付模板

模板按任务简化，不要求用户逐项填写，也不把内部清单全抛给用户。

## 本轮任务卡

```text
任务：
编辑母版：绝对路径 / SHA-256 / 版本
标注图：路径，与母版的对应关系
输入角色：母版 / 构图参考 / 产品正面 / 侧面 / 安装图纸 / 风格参考
目标对象：数量、名称、位置；避免“这里”“那个”
必须修改：可观察的缺陷与期望变化
必须保留：人物、构图、产品四角、纹理、背景、尺寸等
禁止增加：物体、文字、按钮、logo、框架、阴影等（按本轮）
已确认项：反馈原话 / 对应版本 / 认可范围
允许范围：掩膜路径、坐标基准、必要的衔接范围
真实素材：包名 / 成员 / 型号 / SHA-256 / 参考或合入
输出：格式、像素尺寸、透明要求、正式目录、版本名
验收：目标、回归、技术、视觉、实际使用尺寸
阻碍：缺图、未授权扩大区域、结构证据不足
```

## 局部修图提示词

```text
任务类型：对原图做局部修复。
图1是唯一编辑母版；图2用于标记目标，不把圈线带进结果；图3仅是指定产品侧框参考。
只修：右侧横放板的左右两条竖向框边及必要的四角衔接。
问题：框边侧向与板面冲突，出现双黑边、黑片、接缝与扭转感。
要求：框体与现有板面形成一个刚性物体，侧面方向、厚度、转角、亮暗及材质连续。
锁定：板面四角坐标、所有电池片和格线、人物、肤色、衣服、背景、相邻产品、画布和裁切。
禁止：自由重画整图、移动或旋转板面、改变型号细节、加厚黑边掩盖问题、新增夹具或文字。
输出：按本轮规定的原尺寸和格式；结果必须接受实际文件核验。
```

**提醒**：提示词中的“不变”是目标，不是工具已做到的证据。工具不支持掩膜参数时不能虚构此参数；同样不能声称依赖该参数保证保护。

## 全新模块配图提示词

```text
用途：品牌网站 [模块名称] 配图。
主题：用真实可理解的视觉表达 [主题]，不扩展成未证实的性能或认证。
产品依据：图1正面、图2侧面为 [实际型号]；准确对应片区、格线、边框及厚度。
构图：沿用本系列已确认 [具体约束]，最终网页图 [宽×高]，保留真实高清母版。
材质与光线：[具体自然光源与材质表现]。
不可出现：[无文字/按钮/logo/多余物体等，按任务]。
核验：产品、空间关系、自然物、清晰度与实际裁切都通过后再交付。
```

## 回归表

| 项目 | 采用哪一版本/来源 | 允许改变吗 | 核验结果与证据 |
|---|---|---|---|
| 人物 | 原照片 | 本轮禁止 | 保护区差异＋视觉 |
| 产品位置与透视 | 用户认可的构图版 | 本轮禁止 | 四角与整板对照 |
| 产品纹理 | 指定型号原素材 | 按本轮范围 | 来源＋片区/方向对照 |
| 厚度与四角 | 正侧面素材与当前空间 | 仅目标边 | 整板和四角放大 |
| 背景与文字区 | 现行母版 | 本轮禁止 | 区外差异＋页面裁切 |

以上是示例，不默认任何任务都包含这些对象。

## 交付表述

```text
已修正 [明确对象与缺陷]，输出 [宽×高、格式]。
[正式文件链接]；[前后对比链接，用户需要时]。
核验：[实际完成的检查]。
状态：[修订稿/技术通过/视觉自检通过/用户最终确认]。
限制：[具体尚未证实项；没有则省略]。
```

不能写“全都没问题”“逐像素保留”“完全使用原素材”“原生4K”“最终确认”，除非对应证据成立。用户要精简时只保留结果和必要限制。
