# 具体工作方法

## 1. 全新生图与按内容配图

先明确页面内容和视觉要表达的事实。防眩光、轻量化、防冰雹和防积尘不是同一个场景换标题：每张图有明确视觉主题，但必须沿用该系列已确认的产品、光线、尺寸及有字/无字要求。

“只参考尺寸”不意味着参考其画面；“重新生成”不等于在原图上调暖色。模块主题先用一句可视化的真实场景表达，避免把小灯和太阳能板硬拼成解释不通的组合。按目标比例组织主体、留白和信息密度，不靠生硬截屏凑尺寸。居中文字模块需要中央可读区并向两侧自然过渡，不默认主体必须居中。

生成前建立：用途、目标尺寸/长宽比、主体、真实产品依据、场景、光源、文案安全区、不得出现的内容。用户说“按上一张要求”时从当前任务前文恢复共同约束，单独更新主题；不能跨任务借用尺寸和型号。

真实感检查：

- 主体符合真实使用语境，环境和物体尺度一致；住宅、阳台、栏杆与安装方式可信。
- 光源方向、明暗、反射、接触阴影和环境色统一。不能用“电影感”代替产品清楚。
- 不出现无来源的植物、椅子、坐垫、假连接件、铁丝、文字或按钮。
- 植物、人体和自然物具有合理形态；不要靠过量锐化、颗粒、景深或虚化掩盖错误。
- 若用户授权创意探索，可给不同方向；一旦确认构图，后续转入编辑模式锁定画面。
- 不把示意画面当性能测试证据，冰雹回弹效果不能证明抗雹等级；不得自行生成认证字样。

## 2. 局部修复：边界、上下文与保护

1. 同时打开无标记原图和标注图。标注只负责定位；避免将圈线、箭头或截图浮层带进成稿。
2. 定义目标对象及最小合理工作范围，包含确需修复的轮廓、反射、接触阴影和端点衔接。不能把目标轮廓紧贴到没有任何衔接余地，也不能无限放大区域。
3. 保存执行前的允许修改掩膜与人物、建筑、文字等关键保护区。允许区与保护区冲突时先解决冲突，不能自动偏向生成器。
4. 按当前授权和工具规则编辑。局部输入需要足够上下文，让工具理解邻接与空间；这不代表上下文都获准修改。
5. 检查候选是否改变尺寸、视角、边缘坐标、人物和板面。当前工具只提供完整候选时，不直接默认该候选满足像素保留要求。
6. 只有当前规则允许并且已有授权时，使用原始母版与局部结果合成；否则说明严格保留的技术限制并选择可行路径。所有合成都应保留原图与中间层，不覆盖。
7. 保存最终文件后做像素检查。掩膜外变化非零时先定位变化，再处理；禁止为了得到零而事后把范围扩大。
8. 最后看整图及真实使用比例。范围正确但内容错误仍然失败。

**去物体**：区分物体本体、其自身阴影、遮挡露出的背景和相邻真实构件。去掉夹具后要接顺栏杆，但不能删掉支撑逻辑所需的其他连接。遇到水印请求按当前政策处理用户指定目标，不能交付不相关的移动/裁切操作。

**留白**：用户要左侧文字空间时，保留画布与主体，局部处理亮度、对比或背景信息。只有用户授权才移动主体、裁切或全图重生成。检查文字实际放进去后的可读性，而非把整片刷白。

## 3. 指定真实组件替换

### 素材可信链

- 先确认压缩包可读取；`.zip`、`.larkcache`后缀不等于格式。列出实际成员，避免把临时缓存包当成完整资源。
- 解包时排除绝对路径、`..`及越界链接，保留原始包；不要在用户目录随意覆盖同名文件。
- 建立正面/背面/侧面/特写的接触表，按用户指定型号选择。54HJBB、54HVBB、54HVD的相似命名不可混用。
- 记录压缩包路径、成员名、成员SHA-256与解出文件SHA-256；记录裁切/旋转/投影步骤。
- “参考生成”：生成器看过产品图，但像素由生成器重绘。
- “真实素材合入”：实际采用指定图像内容进行替换，可追踪到成员与最终可见部位。
- 两者都要做视觉核对；真实素材合入也可能因旋转、插值、遮挡或局部重绘而失真。

### 产品特征核对表

逐块标记型号和安装方向，核对电池片分区、横竖栅线、片数及比例、汇流分隔、正面黑度、内沿颜色、外框颜色、真实厚度和可见侧面。原图没有依据的纹理不得凭“太阳能板通常长这样”补出。

横放只改变产品在画面中的方向，不能任意改变内部结构。玻璃反射和照明可按场景合理匹配，但不得抹掉识别该型号的关键细节。

## 4. 透视、厚度和转角

### 先判定空间，再改纹理

记录整块板四角、正面边界、可见侧面、安装倾角、遮挡层级与背景关键线。已确认四角就锁住；只修边时不得移动四角。若四角本身就是错误目标，应明确本轮允许移动哪些点。

正面为平面时，透视投影应来自一套一致关系。侧面不是对正面做一次简单平移就总能成立：要结合厚度、相机、可见面方向和产品真实截面。单应变换只描述平面投影，不能单凭一套矩阵证明完整三维正确。

对于两条竖边：

1. 看整块板，确定左/右侧哪些面应该可见，不能两边随意外翻。
2. 让正面、侧框和上下框按同一物体几何衔接；允许不同面有不同平面映射，但它们的公共边必须重合。
3. 检查四个角的交点、斜切关系、内外沿线与明暗。不应有黑色刀片、重复压条、突然的宽度跳变。
4. 纹理、反光方向和锐度连续。过度羽化会把硬边抹糊，不能用模糊盖住结构接错。
5. 同时看原始像素和网页缩小图：放大能看见接缝，缩小能看出整块板是否“扭”。

多块板要先判断是否同平面、同规格、同倾角。不能简单要求所有边平行，也不能凭近大远小就断言错或对。结构证据不足时写“尚不能验证空间关系”，而非编造角度。

## 5. 支架与安装结构

依据用户提供的图纸、真实产品照片和明确型号检查可见连接。图纸负责形状和连接依据，照片可补材质；没有注明的表面颜色、隐藏背架或内部构造不能伪称已验证。

从栏杆/墙体固定点追到连接件、支撑杆、组件背框，检查是否有穿透、无接点悬空、螺栓缺失、错用压片或受力关系不成立。图纸中的某个部件并非任何视角都必须画出来；以视角与遮挡解释是否可见，不为凑齐零件数量乱加。

对EUP020案例的正确复用是“按当前图纸检查可见连接”，不是所有阳台图都删除下角夹具。无完整结构证据时交付“安装示意”，用户需要工程还原则要求对应三维/尺寸/安装材料。

## 6. 人物保留、肤色和去AI感

“肤色还原”与“人物不变”是不同要求。把生成版平均肤色调近原图，不会恢复脸形、表情、衣服褶皱、发丝和原照片纹理。

人物必须不变时，优先采用当前授权允许的原始人物保留路径；登记人物保护区、原图尺寸与任何用户允许的缩放。若整体缩放已获授权，只能称相对于该确定性缩放基准保持，不能称原尺寸原始像素完全相同。

清理蜡感时保留真实皮肤起伏、毛孔、自然明暗和肤色变化；不要一层噪点或高反差锐化冒充皮肤。白点只处理异常点，不抹掉高光、眼白和发丝。手部检查解剖、握持、接触和遮挡。

## 7. 冰雹、云和金属的真实感

- 冰雹：形状有差异，浑浊冰芯和半透明边缘并存；不能统一规则球、白色雪团、毛绒或玻璃珠。与板面接触、运动方向、尺度和光线一致。用户只否定冰雹时，板面和构图继续锁定。
- 云：只调整指定区域的浓淡与柔硬，保护建筑轮廓和交界。避免一侧像绘画、一侧像照片；不要顺便换太阳或色温。
- 不锈钢：光泽来自环境反射及粗糙度，不是通体纯白；边缘高光、拉丝/微纹理和阴影须适量并与尺度一致。
- 黑色铝框：仍有可解释的转折与微反射；不应把所有边涂成无层次纯黑，也不应统一做亮银倒角。

## 8. 清晰化、缩放与原图找回

先问清“找回原始高清”还是“增强现有小图”，能从上下文分清就直接做。找回优先检查本机生成原件和相应历史记录；同主体但场景不同不算同一原图。比较构图、物体、反光、边缘及裁切；尺寸增大本身不能证明找到原件。

同尺寸增强锁定宽高与透明内容；去噪与锐化应在100%看是否有光晕、伪纹理和涂抹。放大插值、AI补细节和原生生成分别说明，不把插值叫真实信息恢复。

要缩小130×130画布里的主体时，画布不变、主体同比缩小并居中；检查光学居中与透明边，不新加框架、斜面或阴影。若用户明确选了非等比拉伸则按该选择操作，不私自改为裁切或补白。

高清母版与454×204、220×165等网页小图分开保存，并记录从哪个母版按哪种裁切/缩放生成。网页交付图不必无限放大，但应能追溯真实高分辨率来源。

## 9. 失败后的决策

| 失败类型 | 优先处理 |
|---|---|
| 修错图/对象/版本 | 回到输入和任务卡，废弃错误候选的交付资格 |
| 素材型号错误 | 重新核对原包及成员，不靠调色掩盖 |
| 几何不成立 | 先重建共同空间关系，暂停材质润色 |
| 几何正确但接缝明显 | 检查轮廓、采样、遮挡、锐度和局部色差 |
| 工具反复重绘保护区 | 说明能力限制，采用获授权的范围控制路径 |
| 当前局部修复已无法保持既定条件 | 保存母版，提出最小必要扩大范围；已有重生成授权才重生成 |
| 缺少原图/关键图纸 | 继续整理可做部分，暂停依赖缺件的正式生成 |

不能因为用户要求“直到改好”就无限后台运行、自动保证睡眠时继续或偷偷创建定时任务。需要后台/监控时使用该环境支持的明确授权机制，交代运行条件和真实状态。
